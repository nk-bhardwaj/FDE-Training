To ensure a consistent experience for buyers, you must match or exceed Amazon's return policies.

If a buyer requests a return, we will send you an e-mail that includes the reason for the return. We recommend that you respond to return requests within 24 hours. If the buyer’s request does not comply with our return policy, details will be provided in the e-mail.

Return labels
When you approve a buyer’s return request, we send them a return label that includes your default return address or an alternative return address that you can set in Return settings. By default, the return label is not prepaid. For more information, go to Return labels.

Cancelled returns
If a buyer contacts you directly to cancel a return request, ask them to cancel it through their Amazon account. You will get an e-mail when buyers cancel requests.

Refund options
If you authorise the return request and want to refund the order, you can choose from several options. For more information, go to Refund orders. We encourage you to wait until you receive a returned item before issuing a refund so you can evaluate its return condition.

You can also issue a concession instead of or in addition to a refund. For more information, go to Issuing concessions.

If the buyer says the order never arrived, go to What if a buyer says they did not receive their order?.

Fulfilment by Amazon (FBA) orders
We manage returns and refunds of orders shipped through Fulfilment by Amazon. To learn how we manage Fulfilment by Amazon returns, go to Fulfilment by Amazon customer returns.
